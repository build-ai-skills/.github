## 🎯 Who these courses are for

✓ Working developers comfortable with git, the shell, and at least one of Node, Python, or Go
✓ Engineers who use AI tools daily but feel stuck at "fancy autocomplete"
✓ Indie hackers and senior ICs who want to ship with AI, not just talk about it

These courses are **not** for absolute beginners to programming — we assume you can already build software, and teach you how to do it faster and bigger with AI.
